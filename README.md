# Luh Krisnawati — Personal Academic Website

Personal academic website for Luh Krisnawati, S.T., M.T.

## Files

- `index.html` — main website
- `style.css` — website styling
- `script.js` — navigation, mobile menu, year, and back-to-top button

## GitHub Pages

Create a repository named:

`USERNAME.github.io`

Upload these three files to the root of the repository:

```text
USERNAME.github.io/
├── index.html
├── style.css
└── script.js
```

Then go to:

Settings → Pages → Build and deployment → Deploy from a branch

Select:

`main` → `/ (root)`

The website will be available at:

`https://USERNAME.github.io/`
